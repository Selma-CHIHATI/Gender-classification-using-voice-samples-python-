
a real-time gender classification application that uses voice recordings to identify a person's gender. 

The application is designed to record audio, preprocess it to extract relevant features, 
and predict the gender using a pre-trained XGBoost machine learning model
(XGBoost proved to be the most accurate, with an accuracy of 90.74%).

The graphical user interfaces (GUI), implemented in Python, is built with the PyQt5 library

________________________  The final model XgBoost is saved in "xgboost_model.pkl"
